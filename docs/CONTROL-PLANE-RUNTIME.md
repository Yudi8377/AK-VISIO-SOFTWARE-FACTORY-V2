# CONTROL PLANE RUNTIME

The first executable factory slice is now contract-driven:
1. receive natural-language intent;
2. bind organization scope;
3. create versioned Business DNA;
4. create a deterministic generation plan;
5. evaluate policy;
6. create draft artifacts;
7. advance artifacts only through governed lifecycle states.

This runtime is intentionally independent of any model provider. Model adapters can be connected later without changing the business contract.
