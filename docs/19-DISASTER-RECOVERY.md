# Disaster Recovery

## Sasaran
Menjaga kemampuan mengembalikan control plane, database, deployment, dan audit evidence setelah kegagalan besar.

## Prioritas
1. Identity/access boundary.
2. Database integrity.
3. Control plane.
4. Deployment path.
5. Audit lineage.
6. Non-critical UI/features.

## Uji
DR harus diuji berkala melalui controlled restoration atau equivalent verification. Hasil test menjadi evidence dan menghasilkan remediation item bila ada gap.
