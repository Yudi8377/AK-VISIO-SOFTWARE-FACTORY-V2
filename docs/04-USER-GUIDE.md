# Panduan Pengguna

## Alur utama
**Pusat Kendali → Permintaan → Eksekusi → Validasi → Go-Live → Audit.**

### Permintaan
Masukkan kebutuhan bisnis/teknis secara jelas, termasuk tujuan, scope, acceptance criteria, dan risiko.

### Eksekusi
Factory membentuk execution plan dan menghasilkan artifact terkontrol.

### Validasi
QA/security dan build gate harus lulus sebelum release.

### Go-Live
Promosi dilakukan melalui release/deployment control dan production verification.

### Audit
Gunakan Jejak Audit untuk menelusuri keputusan, eksekusi, deployment, dan recovery.
