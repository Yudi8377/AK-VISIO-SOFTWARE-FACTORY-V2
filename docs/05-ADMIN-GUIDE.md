# Panduan Administrator

## Tanggung jawab
- Mengelola akses dan capability.
- Menjaga environment configuration.
- Memantau execution/release/recovery.
- Meninjau audit.
- Menjaga backup dan recovery readiness.

## Aturan akses
Gunakan least privilege dan separation of duties untuk aktivitas berisiko tinggi. Jangan membagikan credential administrator.

## Perubahan berisiko tinggi
Perubahan production, security control, database, provider, dan recovery policy harus melewati gate yang ditetapkan.
