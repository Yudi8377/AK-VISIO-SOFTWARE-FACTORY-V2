# Panduan Troubleshooting

## Build gagal
Periksa dependency lockfile, TypeScript, lint/test output, dan environment contract.

## Production check gagal
Periksa deployment status, runtime response, route contract, authentication boundary, dan provider logs.

## Recovery gagal
Periksa incident state, lease/scheduler authorization, provider acceptance, dan recovery policy.

## Database gagal
Periksa project target, migration state, RLS, connection configuration, dan schema compatibility.

## Aturan
Perbaiki root cause; jangan menonaktifkan security control untuk membuat check hijau.
