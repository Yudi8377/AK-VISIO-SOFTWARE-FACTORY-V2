# AK VISIO ENGINEER

AI Engineering Intelligence, Troubleshooting, Repair, QA & Deployment Platform.

## Foundation
Phase 1 establishes the shared core for Administrator Edition and standalone offline specialist modules.

### Principles
- Offline-first
- Evidence before action
- Human approval for high-risk/destructive/production actions
- Signed/versioned modules
- Existing AK VISIO Software Factory remains protected and is integrated later as the SOFTWARE ENGINEER module

## Runtime baseline
- Tauri 2.x
- React 19.3
- TypeScript
- Node.js 24 LTS
- SQLite 3.53.x-compatible
- npm workspaces
