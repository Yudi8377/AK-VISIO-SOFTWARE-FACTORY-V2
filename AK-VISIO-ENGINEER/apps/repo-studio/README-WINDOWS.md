# AK Repo Studio — Windows Quick Start

1. Make sure Node.js 24.x is installed.
2. Open this folder in Windows Explorer.
3. Double-click RUN-AK-REPO-STUDIO.bat.
4. Your browser opens http://127.0.0.1:4317.
5. Keep the launcher window open while using the app.

The app is local-first. It does not deploy, alter production, or connect to external networks in v0.1.
