# AK Repo Studio Design Context
Audience: AK VISIO engineers/operators importing third-party repositories safely.
Visual direction: dark engineering workbench; quiet surfaces, mint safety signal, dense evidence output.
Signature: ZIP → ANALYZE → PLAN → APPROVE.
Accessibility: semantic controls, visible focus, keyboard-operable inputs, responsive layout.
Behavior: production, destructive and external-network actions remain disabled until governed integration.
