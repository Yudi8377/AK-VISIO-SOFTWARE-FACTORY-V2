# AK Repo Studio — Design Context
Version: 0.4
Audience: engineers/operators importing open-source or ZIP projects into AK VISIO ENGINEER.
Single job: make a repository understandable and safely prepared for integration before any write action.
Visual direction: local engineering workbench — dark graphite, instrument-panel density, restrained mint signal accent.
Tokens: #080b10 background, #111923 surface, #202a36 line, #8df0c4 signal, #eaf0f6 primary text, #8d9aaa muted.
Typography: system UI for reliability; compact utility labels and technical headlines.
Signature: the five-stage evidence rail: Import → Sandbox → DNA → Compatibility → Approval.
Behavior: no native dialogs; explicit states; production/destructive/network/dependency-install gates remain visible and off.
Accessibility: semantic controls, visible focus, keyboard operation, reduced-motion support, WCAG 2.2 AA target.
